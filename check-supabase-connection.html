📝 Setup Instructions

To connect Supabase:

1. Go to Supabase Dashboard
2. Select your project → Settings → API
3. Copy your Project URL and anon public key
4. Update index.html lines 804-805 with your credentials
5. Run the SQL setup script: server/supabase-setup.sql in Supabase SQL Editor
